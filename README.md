# Wordezy Ladder

A daily word-ladder game for [bgameworld.com](https://bgameworld.com), alongside Wordezy, Wordezy Search, Wordezy Scramble and When & Where.

Every day there's one ladder: climb from a 4-letter start word to a 4-letter target by changing one letter at a time, and every step must be a real word. Each ladder has a par (the fewest moves possible, 4 to 6). Everyone gets the same ladder; it's generated from the date, so nothing has to be fetched.

- **Daily**: free, one ladder a day. The clock starts when the player presses Play and survives a reload, and a finished ladder can't be replayed. Undo is free; a hint fills in the best next word but costs an extra move. Results share as a spoiler-free grid.
- **Classic Unlimited**: endless ladders in 4 or 5 letters, with free hints and a "Show route" button. Gated behind a one-time $2 unlock, which is a stub until payments are set up (same as the other games).
- **Leaderboard**: same Supabase project and account system as the other Wordezy games. Ranked by fewest moves, then time. Only a player's first finish each day counts.
- **Achievements, streaks, best time**: stored on the device.

## Run it locally

```bash
npm install
cp .env.example .env.local   # same Supabase URL and anon key as the other Wordezy games
npm run dev
```

## Database

The leaderboard needs `supabase/migrations/20261008_wordezy_ladder.sql`. Run it once in the Supabase SQL editor for the Wordezy project. It only creates new `wordezy_ladder_*` objects. Until it's run, the game still works and the leaderboard stays hidden.

## Deploy (Cloudflare)

Same setup as the other games:

1. Push this repo to GitHub.
2. In Cloudflare, create a Worker from the repo. Build command `npm run build`, deploy command `npx wrangler deploy` (see `wrangler.jsonc`).
3. Add the `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` build variables.
4. Add the custom domain `wordezyladder.bgameworld.com`.
5. In Google Search Console, submit `https://wordezyladder.bgameworld.com/sitemap.xml`.

## SEO

`index.html` has the title and description, canonical URL, Open Graph and X/Twitter cards with `public/og-image.jpg`, `VideoGame` structured data, a `<noscript>` description, icons and a web manifest. `public/robots.txt` and `public/sitemap.xml` point at the subdomain.

## Word lists

`src/data/words.ts` is generated by `scripts/build_words.py`:

- **VALID**: every word a player may type (4- and 5-letter everyday English words).
- **CORE**: the more common subset that par, the shown route and hints use, so par never depends on an obscure word. A player who knows a rarer word can beat par.
- **ENDS**: well-known words used as start and target.

Names, slang and offensive or grim words are filtered out. Sources, cloned from GitHub into a download folder before running the script:

- [dolph/dictionary](https://github.com/dolph/dictionary): `popular.txt` (from the public-domain ENABLE list)
- [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords): `content/2018/en/en_50k.txt`, used only to rank words by everyday use

```bash
python3 scripts/build_words.py src/data/words.ts path/to/downloads
```

Changing the lists changes which ladders future days get, so avoid regenerating mid-day once the game is live.
